# Introduction to Networking

## What is Networking?
Networking is the process of connecting computers and devices so they can communicate, share data, and use common resources.

---

## Why Networking is Needed?
- File and resource sharing
- Internet access
- Communication (email, video calls)
- Centralized servers and databases
- Cloud computing

---

## How Networking Works (Simple Flow)
1. A device sends data
2. Data is broken into packets
3. Packets travel through switches and routers
4. Destination device receives and reassembles data

---

## Real-World Example
When you open **google.com**:
- Your system sends a request
- DNS converts domain name to IP
- TCP connection is established
- Data is transferred securely

---

## Interview Points
- Networking enables communication between devices
- Works using protocols like TCP/IP
- Backbone of internet, cloud, and DevOps
